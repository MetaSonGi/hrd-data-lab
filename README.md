# HRD 데이터랩 🛰️

한국산업인력공단 MCP 서버(`openapi.hrdkorea.or.kr/mcp`)에 브라우저에서 직접 연결해
국가자격·해외취업·NCS·일학습병행·숙련기술·EPS 데이터를 실시간 조회하는 탐색 사이트.

🌐 **바로 실행:** https://metasongi.github.io/hrd-data-lab/

## 기능

- **🏆 자격증 대시보드**: 종목명 입력 → 시험일정·상세정보·응시수수료·합격률을 한 번에 병렬 조회
- **🔧 분야별 도구 탐색기** (6개 분야 42개 도구): 각 도구의 입력 스키마를 읽어 폼을 자동 생성, 결과는 마크다운 렌더링
  - 국가기술자격 8종 (Q-Net): 종목검색·시험일정·수수료·합격률·시험장·공개문제·결격사유
  - 해외취업 10종 (월드잡플러스): 채용공고·우수일자리·설명회·국가정보·통계·K-Move
  - NCS 6종: 능력단위 15,000건 검색·연계자격·학습자료·분류체계·블라인드 채용
  - 일학습병행 7종: 과정평가형·참여기관·외부평가·통계
  - 숙련기술 4종: 대한민국명장·작품전시관·기능경기 통계
  - EPS 7종: EPS-TOPIK 일정·시험장·교재·구직자·교육
- **🤖 AI 연결 가이드**: ChatGPT·Claude에 MCP 서버 등록하는 방법 안내 (푸터)

## 기술

- Vanilla JS + MCP Streamable HTTP (JSON-RPC 2.0, SSE 파싱)
- 인증키 불필요 — 서버가 CORS를 허용(`Access-Control-Allow-Origin: *`)해 브라우저 직접 호출 가능
- 조회 실패 시 재시도 (최대 3회, 백오프)
- GitHub Pages 정적 호스팅

## 데이터 출처

한국산업인력공단 오픈API MCP 서비스 (https://openapi.hrdkorea.or.kr/mcp.html)
